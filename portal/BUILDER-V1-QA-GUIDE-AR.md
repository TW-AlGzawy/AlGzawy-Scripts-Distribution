- API الموقع المنشور وCloud Bridge المنشور لا يعرفان معرّف algzawy-builder-v1 حتى الآن.
- لا تثبّت محمّل v1.0 الإنتاجي أو تستبدل السكربتات لدى المشتركين قبل تهيئة الاختبار السحابي.

1. عطّل QA7 المستقل وكل إصدارات البناء القديمة في ملف Tampermonkey التجريبي، وحدّث صفحة اللعبة.

3. يلزم قبل التجربة إعداد جسر QA يوجّه إلى رابط Preview، ومحمّل QA يجلب محرك v1.0 من فرع PR؛ لا تستخدم الجسر والمحمّل الموجّهين إلى main لهذا الاختبار. يلزم حساب تجريبي وجهاز معتمد وصلاحية algzawy-builder-v1 في بيئة QA.
4. اختبر داخل اللعبة: مستخدم مصرّح له وقرية تجريبية ومهمة بناء صغيرة؛ مستخدم دون صلاحية؛ جهاز غير معتمد؛ تعطيل السكربت من لوحة التحكم؛ تعطيل عام؛ تنبيه التحقق البشري؛ استعادة ترتيب طوابير البناء والقوالب.

6. بعد نجاح الاختبارات، راجع PR #14 ثم انشر عبر دمج موثّق وخطة تحديث Tampermonkey، لا عبر نسخ ملفات تجريبية عشوائيًا.
