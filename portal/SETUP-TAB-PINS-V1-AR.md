# AlGzawy V1.0 — نشر محمي (22 أكتوبر 2026)

هذا إصدار **مرشح للمراجعة وغير منشور** إلى حين تنفيذ ترحيل D1 والفحص النهائي. لا تعدل المفتاح المركزي ON/OFF.

## قاعدة Cloudflare الحالية
اسم القاعدة: `algzawy-control-db`. خذ نسخة احتياطية أولًا، ثم نفّذ الأمرين التاليين واحدًا تلو الآخر في D1 Production Console:

```sql
CREATE TABLE IF NOT EXISTS portal_archived_users (
  user_id TEXT PRIMARY KEY REFERENCES portal_users(id) ON DELETE CASCADE,
  archived_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```
```sql
CREATE INDEX IF NOT EXISTS portal_archived_users_date
ON portal_archived_users(archived_at);
```

تأكد:
```sql
SELECT name,type FROM sqlite_master
WHERE name IN ('portal_archived_users','portal_archived_users_date');
```
المطلوب صفان: table و index. لا تحذف أو تغير الجداول السابقة.

## ما سيتغير بعد دمج Pull Request
- جلسة المشترك: `168` ساعة (7 أيام) باستخدام HttpOnly Cookie. الجلسات القديمة الموقعة بصيغة 96 ساعة ستحتاج دخولًا جديدًا مرة واحدة.
- إدارة الحسابات المعطلة: أرشفة؛ استعادة كحساب معطل؛ حذف نهائي بتأكيد DELETE. حذف المستخدم يحذف بياناته التابعة مع ON DELETE CASCADE. لا يمكن حذف حساب نشط.
- تنبيه المخازن: حفظ مكان نافذة الإعدادات وطيّها محليًا.
- قائمة كل سكربت داخل Cloud Bridge: 📌 تثبيت هذا السكربت في هذا التبويب. التشغيل غير المثبت ممنوع. التثبيت محلي للتبويب ولا يشكل ترخيصًا أو بديلًا عن توقيع الجهاز.
- 25 سكربتًا مرخصًا: اسم عربي موحد `تجريبي - الغزااوي - [اسم السكربت]` وإصدار Tampermonkey `1.0` ظاهر وداخلي. جميع Script IDs ومسارات التوزيع بقيت كما هي.

## مهم جدًا — تثبيت Tampermonkey
لأننا خفضنا قيمة `@version` في جميع الـLoaders وفي Cloud Bridge إلى `1.0` بناءً على طلب المالك، قد لا يعرض Tampermonkey تحديثًا تلقائيًا للإصدار الجديد. يجب تحديث/إعادة تثبيت **Cloud Bridge أولًا** ثم الـLoaders اللازمة داخل المتصفح التجريبي مرة واحدة. لا تثبت النسخ الأصلية في `scripts/` كتطبيقات منفصلة؛ ثبّت `loaders/` فقط.

## QA بعد إعداد الجدول والدمج
1. تحقق من بقاء `/api/status` كما هو (ON/OFF وrevision دون تعديل).
2. حساب نشط: لا تظهر الأرشفة أو الحذف؛ حساب معطل: تظهر الأرشفة والحذف؛ أرشفة/استعادة لا تفعّل الدخول؛ الحذف النهائي لا يمس الحسابات الأخرى.
3. تحقق من جلسة 7 أيام، تسجيل الخروج، تعطيل الحساب وإبطال الجلسة.
4. ادخل لعبة Tribal Wars: افتح تبويبين؛ في Cloud Bridge ثبّت سكربتًا واحدًا بالأول. لا تشغّله في الثاني؛ تحديث الأول لا يزيل التثبيت. جرّب **Duplicate tab** أثناء بقاء الأصل مفتوحًا ويجب أن يبدأ المنسوخ دون تثبيت.
5. انقل نافذة المخازن وصغّرها ثم حدّث اللعبة؛ يجب أن تعود في مكانها.
6. أوقف الترخيص/الاشتراك لتتأكد من أن التثبيت لا يتجاوز الحظر.

الاختبارات الساكنة وUnit Tests ليست بديلاً عن QA فعلي داخل اللعبة. لا يعتبر المشروع صالحًا للبيع حتى نجاح التحقق على متصفح حقيقي.
